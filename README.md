WASH KAP Assessment Dashboard - Pre/Post Intervention Comparative Analysis
WASH KAP Assessment Dashboard
Knowledge, Attitudes & Practices (KAP) Pre- and Post-Intervention Comparative Report

Important Note: 
This dataset is sample/fictional data created for educational and portfolio purposes only.  
It does not represent real individuals or actual events.


Project Overview

This project presents an interactive Excel dashboard analyzing WASH (Water, Sanitation, and Hygiene) Knowledge, Attitudes, and Practices (KAP) survey data collected before and after a humanitarian intervention.

The dashboard visualizes key indicators across:
- Water Access & Infrastructure
- Hygiene Knowledge & Practices
- Water Treatment & Safe Storage
- Sanitation & Garbage Disposal
- Diarrhea Prevention & Incidence
- Community Engagement & Remaining Needs


Tools Used

- Microsoft Excel (Power Query, Pivot Tables, Charts, Slicers)
- GitHub (Portfolio hosting)


Dashboard Features

| Feature | Description |
| Interactive Dashboard | Slicers for governorate, gender, and family size 
| Comparative Analysis  | Before/after comparison across 97 survey fields 
| Key Indicators        | 25+ KPIs tracked (diarrhea incidence, handwashing, water treatment, etc.) 
| Data Cleaning         | Duplicate removal, empty columns, standardized naming
